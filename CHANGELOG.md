# Changelog

## 0.1.0

First public npm release as `@wieslawsoltes/dockyard`.

- Existing dependency-free Dockyard docking library with observable layout models, PascalCase APIs, custom elements, document/tool panes, floating windows, auto-hide and layout serialization.
- Typed ES module and layout-model package exports, stylesheet export and standalone browser distribution.
- Node 22/24 checks, Chromium interactions and HTTP/persistence verification, plus tests against the actual installed package.
- Immutable GitHub release archives, GitHub Packages and public npm publication with provenance and anonymous registry verification.
- README installation instructions and repository, npm, release, license and demo badges.

The compatibility report continues to document browser adaptations and AvalonDock/.NET boundaries.
